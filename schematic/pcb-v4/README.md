# PCB V4 đang phát triển

[Mở project KiCad](candidate.kicad_pro)

Bản sao từ PCB ủi được lưu trên máy ngày 25/11/2026. Thiết kế đang chỉnh,
chưa đủ điều kiện chế tạo. KiCad CLI lần kiểm tra tích hợp ghi nhận 93 lỗi
clearance, 4 lỗi đường biên, 2 sai khác schematic và các cảnh báo. Cần đối chiếu
bản chỉnh tay mới nhất và khắc phục DRC, sau đó thử điện và tải thực tế.
